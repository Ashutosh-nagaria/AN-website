# Ashutosh Nagaria — Portfolio

Live site: **https://ashupfolio-yndcji2y.manus.space/**

Personal portfolio for Ashutosh Nagaria, Product Manager specializing in AI-native enterprise products. Single-file static site: one `index.html` with embedded CSS and JS, no build step, no server.

## What's here

- `index.html` — the full site
- `assets/headshot.jpg` — profile photo

## Run it

Open `index.html` directly in a browser, or serve the folder with any static file server:

```
npx serve .
```

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel, Manus). No build step required.
